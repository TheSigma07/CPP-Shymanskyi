🛠️ Стек технологій та їх роль у проєкті

Технології, використані при розробці та деплої даного сайту канцтоварів PaperCraft:

🌐

HTML5

Роль: Структура вебсторінки

Створення семантичного каркаса сайту PaperCraft: розмітка шапки, навігації, каталогу товарів, кошика покупок та форм.

🎨

CSS3

Роль: Стилізація та адаптивний дизайн

Оформлення зовнішнього вигляду магазину, сітки товарів (Grid/Flexbox), стилізація кнопок, модальних вікон та мобільна адаптивність.

⚡

JavaScript (Vanilla JS)

Роль: Логіка та інтерактивність

Реалізація роботи кошика, інтерактивного пошуку, відкриття модального вікна оплати та обробки подій користувача.

🌿

Git

Роль: Система контролю версій

Відстеження історії змін коду проєкту, фіксація комітів та управління структурою папок.

🚀

GitHub & GitHub Pages

Роль: Хостинг та репозиторій

Збереження сирцевого коду в онлайн-репозиторії та публікація працюючого вебсайту в мережі Інтернет.
