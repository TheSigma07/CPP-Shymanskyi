# PaperCraft — Кросплатформний каталог канцтоварів (Monorepo)

Кросплатформний застосунок для ведення асортименту канцтоварів, миттєвого пошуку та формування кошика покупок, побудований за архітектурою монорепозиторію (`npm workspaces`) зі спільним ядром бізнес-логіки `@papercraft/core` та платформними адаптерами.

---

## Технологічний стек і компетентності

### Архітектура та стек технологій

| Рівень архітектури | Технології | Реалізація в монорепозиторії |
| :--- | :--- | :--- |
| **1. Платформи** | Web (Desktop / Mobile браузери), Desktop (Windows / macOS) | Запуск у браузері (`http://localhost:3000`) та як окремого віконного застосунку Electron |
| **2. Клієнтські технології** | HTML5, CSS3, ES Modules (Import Maps), Electron (`contextBridge`, IPC) | Веб-клієнт у [`packages/web`](./packages/web) та десктопний клієнт у [`packages/desktop`](./packages/desktop) |
| **3. Спільний код** | JavaScript (ESM), `npm workspaces`, Dependency Injection, `node:test` | Платформонезалежне ядро `@papercraft/core` у [`packages/core`](./packages/core) |
| **4. Сервер і API** | Node.js (`node:http`), HTTP / REST | Локальний HTTP-сервер роздачі статики із захистом шляхів у [`packages/web/server.js`](./packages/web/server.js) |
| **5. База даних та сховища** | Web `localStorage`, Node.js `fs/promises`, JSON | [`LocalStorageAdapter`](./packages/web/localStorageAdapter.js) (Web) та [`FileStorageAdapter`](./packages/desktop/fileStorageAdapter.js) (Desktop) |

### Компетентності розробника

У межах розробки кросплатформного проєкту **PaperCraft** здобуто та закріплено практичні навички:
* **Архітектурне проєктування:** організація монорепозиторію через `npm workspaces` та виділення чистого бізнес-ядра без залежностей від середовища виконання.
* **Кросплатформна розробка:** створення спільного шару бізнес-логіки (`CatalogService`, валідація, пошук, сортування) для веб-клієнта та десктопного застосунку Electron.
* **Безпека десктопних застосунків:** налаштування ізоляції рендер-процесу (`contextIsolation: true`, `nodeIntegration: false`, `Content-Security-Policy`) та побудова контрольованого IPC-мосту через `preload.cjs`.
* **Автоматизоване тестування:** написання модульних та інтеграційних тестів на вбудованому рушії `node:test` для перевірки ядра, адаптерів сховища, IPC-обробників та HTTP-сервера.

## Історія проєкту

| Параметр | Опис |
| :--- | :--- |
| **Назва проєкту** | **PaperCraft** — Кросплатформний каталог канцтоварів |
| **Проблема** | Забезпечення єдиної логіки обліку канцтоварів, пошуку позицій та керування кошиком як у веб-браузері, так і в автономному десктопному застосунку без дублювання коду правил валідації та обробки даних між платформами. |
| **Моя роль і внесок** | Full-stack та Cross-platform розробник: проєктування структури монорепозиторію, виділення спільного ядра `@papercraft/core`, реалізація адаптерів сховища даних, налаштування захищеної IPC-взаємодії в Electron та написання набору автотестів. |
| **Обраний стек технологій** | Використано `npm workspaces` для зв’язування локальних пакетів без публікації в зовнішній реєстр; нативні ES Modules із `<script type="importmap">` у веб-версії для роботи без важких бандлерів; Electron з `contextIsolation: true` для безпечної роботи з локальною файловою системою. |
| **Найскладніший кросплатформний виклик і рішення** | **Виклик:** потреба використовувати єдиний сервіс `CatalogService` у середовищах із різними API збереження даних (`window.localStorage` у браузері та `node:fs/promises` в основному процесі Electron) за умови суворої ізоляції рендер-процесу.<br>**Рішення:** застосовано патерн «Спільне ядро + платформні адаптери» (`StorageAdapter`) із впровадженням залежностей (Dependency Injection) та реалізовано обмежений IPC-міст `window.catalogAPI` у `preload.cjs`. |
| **Здобуті знання та вміння** | Повний цикл створення кросплатформного продукту: від проєктування модульної архітектури й реалізації патернів Adapter та DI до покриття всіх пакетів автотестами (`npm test`) і документування інженерних рішень. |

## Сильні моменти реалізації

1. **Єдине джерело істини ([`@papercraft/core`](./packages/core)):** усі правила валідації (`MAX_TITLE_LENGTH`, перевірка ціни), фільтрація та сортування зосереджені в одному пакеті — зміна правила в [`itemValidation.js`](./packages/core/itemValidation.js) автоматично застосовується в обох клієнтах без зміни їхнього коду.
2. **Ізольована безпека Electron ([`packages/desktop`](./packages/desktop)):** у [`main.js`](./packages/desktop/main.js) та [`preload.cjs`](./packages/desktop/preload.cjs) вимкнено прямий доступ до Node.js із інтерфейсу, а всі операції зі сховищем проходять через перевірені IPC-канали.
3. **Покриття тестами (`npm test`):** усі 3 пакети покриті автоматизованими тестами (`19/19` пройдено через `node --test`), включно з перевіркою стійкості адаптерів до пошкоджених JSON-даних.
